# Линия

Эволюционный роглайт: игрок ведёт линию организмов от протоклетки до сложного многоклеточного существа. Ход игры построен на реальной биологии: на энергетическом бюджете, физических ограничениях и геноме, устроенном как граф.

- Дизайн-документ: https://claude.ai/artifact/15s3mSdtyoXoegBeiZ5HFd

## Структура

| Папка | Назначение |
|---|---|
| `docs/` | Дизайн-документ, баланс, научные заметки |
| `sim-core/` | Ядро симуляции, не зависящее от движка (метаболизм, геном, отбор) |
| `prototype/` | Браузерный прототип основного цикла «жизнь → драфт → отбор» |

## Статус

Пре-продакшн: концепция и дизайн-документ готовы, следующий шаг — эпоха 1 (прокариоты) и прототип.
