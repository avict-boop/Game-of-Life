# Прототип эпохи 1

Один файл `index.html`, без сборки: откройте его в браузере.
Опубликованная версия: https://claude.ai/artifact/JHmvyL3yXJQmpUxjieMTaf

Что проверяем: интересен ли цикл «жизнь → отбор → драфт» на модели энергобюджета из `docs/epoch-1-prokaryotes.md`.

В прототипе: микробный мат (свет и УФ сверху, H₂S снизу, пятна органики), три линии, 12 мутаций из 35, фаги по принципу «убей победителя», летопись после поколения.

`balance-check.js` прогоняет 6 игр по 10 поколений для заданной стратегии и печатает долю линии по поколениям.

Результаты прогона (доля линии к 10-му поколению, 6 игр):

| Стратегия | Итог |
|---|---|
| Без мутаций | 1–12 %, проигрыш |
| Мельче + чистка генома | 1–45 %, обычно проигрыш |
| ЭТЦ + фотосинтез | 4–90 %, в 4 из 6 игр больше 70 % |
| Жгутик + хемотаксис | 21–97 %, в 5 из 6 игр больше 59 % |

Известная проблема: жгутик с хемотаксисом пока сильнее остальных стратегий.
